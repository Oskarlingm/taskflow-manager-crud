# Guia de video y entrega

## Guion recomendado

1. Presentarse y mostrar el repositorio publico.
2. Mostrar las cinco historias en Jira o Azure DevOps.
3. Ejecutar la API con `dotnet run --launch-profile http`.
4. Entrar en `http://localhost:5116` con `admin@taskflow.com` y `TaskFlow123!`.
5. Demostrar crear, consultar, editar y eliminar una tarea.
6. Ejecutar `dotnet test` desde `selenium/TaskFlow.SeleniumTests`.
7. Mostrar las 15 pruebas aprobadas.
8. Abrir `TestResults/TaskFlowReport.html` y las capturas.
9. Publicar en YouTube o OneDrive con acceso abierto.
